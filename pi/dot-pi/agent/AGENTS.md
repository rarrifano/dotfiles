# Global Agent Instructions

- Be concise.
- Make the smallest change that solves the request.
- Read only what you need; prefer `rg`, `find`, and targeted reads over full-file scans.
- Do not add dependencies, abstractions, scripts, or docs unless asked.
- Keep code and config simple and readable.
- When something is ambiguous, ask one focused question.
- After changes, run the lightest relevant validation.
